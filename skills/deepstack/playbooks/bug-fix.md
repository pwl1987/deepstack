# Bug fix 修复

1. 重述可观察症状和完成标准。
2. 按 `../../deep-fix/SKILL.md` 执行根因定位：在匹配的真实表面复现；无法复现时收紧触发条件、补充观测或构造确定性用例。
3. 列出候选机制，按能最大幅度缩小问题空间的顺序验证，直到一个根因得到运行证据支持，并做全库影响面扫描。
4. 只实现证据支持的最小修复；跨函数边界或改变所有权时先按 `../../architect/SKILL.md` 做架构判断。
5. 按 `../../tdd/SKILL.md` 固定根因触发的行为测试，再读取 `../../quality-gate/SKILL.md` 运行相邻测试和项目质量门。
6. 报告原始失败、根因、修复、回归结果和仍未覆盖的路径。

没有原始失败或等价确定性证据时，不能把“应该修好了”写成完成。
