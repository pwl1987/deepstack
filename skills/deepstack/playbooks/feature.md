# Feature 功能

1. 明确用户目标、非目标、数据形状和可观察验收标准。
2. 检查现有模块、平台能力和依赖；先复用，再决定是否需要新抽象。
3. 如果改变模块边界、数据所有权或存在多个高代价方案，先按 `../../architect/SKILL.md` 做架构判断；可独立的工作流才允许并行。
4. 按垂直切片实现，优先按 `../../tdd/SKILL.md` 用行为测试固定契约；每个切片单独验证。
5. 读取 `../../quality-gate/SKILL.md` 运行项目质量门，高风险或大 diff 时按 `../../interrogate/SKILL.md` 做独立代码审查，确认调用方、文档和监控同步。
6. 报告选择、未采用的方案、验证证据和剩余风险。
