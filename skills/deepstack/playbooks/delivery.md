# Delivery 交付

1. 确认交付对象、当前提交、工作区和用户授权范围。
2. 按 `../../ship/SKILL.md` 的交付检查单核对边界、失败路径、权限、数据迁移、调用方和回滚方式。
3. 读取 `../../quality-gate/SKILL.md` 运行项目质量门；高风险或大 diff 时按 `../../interrogate/SKILL.md` 增加独立对抗审查。
4. 检查证据是否对应当前提交，不能用旧结果覆盖新改动。
5. 只在用户明确授权时执行提交、推送、创建或更新 PR、合并或发布。
6. 输出 ready / not ready、阻塞项、命令结果和剩余风险。
