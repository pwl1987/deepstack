# 目标模式

目标模式用于需要多个阶段、长时间推进或跨会话恢复的工程任务。它由 `/deepstack` 自动判断，不需要用户记住额外命令。

目标模式只增加一个小型检查点文件：`.deepstack/goal.md`。文件记录目标、范围、非目标、完成标准、约束、当前阶段、已完成证据、阻塞项和下一步。没有明确的长期目标时不创建它。

每次运行只推进一个可验证阶段。阶段完成、遇到阻塞或需要外部授权时更新检查点并停止。下一次运行先读取检查点、工作区、分支和差异，再继续剩余阶段。

目标模式不承诺后台运行，也不绕过提交、推送、合并、发布或部署的授权边界。宿主无法持久化状态时，必须把检查点输出给用户并标记跨会话恢复为 `UNVERIFIED`。

推荐输入：

```text
/deepstack
目标：完成一次可恢复的数据库迁移
范围：当前仓库
完成标准：迁移可回滚、测试通过、给出发布前检查结果
约束：先只读调查，分阶段推进，每阶段记录检查点
```
